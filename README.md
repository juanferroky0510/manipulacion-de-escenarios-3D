# Manipulación de Escenarios 3D con Three.js

Este proyecto muestra diferentes ejemplos de **manipulación de escenarios 3D en la web** utilizando la librería **Three.js**.  
La aplicación presenta una interfaz web desarrollada con **Bootstrap 5**, desde donde se pueden explorar distintos ejemplos de control de cámara y navegación en escenas 3D.

## Objetivo

Demostrar cómo utilizar **Three.js** para crear y manipular escenarios tridimensionales interactivos en el navegador, aplicando distintos tipos de controles de cámara y navegación.

## Tecnologías utilizadas

- Three.js
- Bootstrap 5
- JavaScript
- HTML5
- CSS3
- WebGL


## Ejemplos incluidos

### 1. Geometry / Minecraft
Genera un mundo tridimensional basado en bloques similar al estilo **Minecraft**, utilizando geometrías repetidas y texturas.

### 2. Controls / Map
Permite explorar un escenario utilizando **MapControls**, con desplazamiento, zoom y rotación similares a los controles de un mapa interactivo.

### 3. Controls / Orbit
Utiliza **OrbitControls** para orbitar la cámara alrededor del escenario, permitiendo inspeccionar los objetos desde distintos ángulos.

### 4. Controls / PointerLock
Implementa **PointerLockControls** para crear una navegación en **primera persona**, similar a la utilizada en videojuegos tipo FPS.

## Controles de navegación

Dependiendo del ejemplo, se utilizan distintos controles:

### MapControls
- Click y arrastrar → mover la cámara
- Scroll → zoom

### OrbitControls
- Click izquierdo → rotar cámara
- Click derecho → mover escena
- Scroll → zoom

### PointerLockControls
- Mouse → mover cámara
- W / A / S / D → desplazarse
- Espacio → saltar
